Fala por fala

    Como ler o placar

    Verdadeiro os fatos confirmam
    Impreciso exagerado ou fora de contexto
    Falso os fatos contradizem
    Sem dados não deu para verificar

    A porcentagem conta só as falas com veredito. "Sem dados" fica de fora.

    Como funciona

    O áudio do debate é transcrito a cada 10 segundos. Uma IA (Jev) separa as afirmações que dão para checar. Outra IA busca cada uma na web, em agências de checagem, imprensa e dados oficiais, e dá o veredito com a fonte.

    As mesmas regras valem para os dois candidatos.

    É uma checagem automática e pode errar. Confira a fonte de cada fala antes de compartilhar.
